■ 이게 뭔가요?
  각자 맡은 영역(평가 / 기술 / 데이터 등)의 발표 내용을 작성하면,
  나중에 하나로 합쳐서 "디자인이 통일된 PPT"로 만드는 팀 공용 키트입니다.
  '평가 영역'이 완성 예시로 들어 있으니, 그대로 보고 따라 하시면 됩니다.

  ※ 마크다운/코딩 몰라도 됩니다. 아래 [1단계] 방법 B 를 쓰시면 돼요.


----------------------------------------------------------------
 [0단계] 파일 세팅  (30초)
----------------------------------------------------------------
  다운로드 받은 파일 전부를 "한 폴더"에 같이 넣어 두세요.
  (폴더 위치·이름은 자유. 파일들이 흩어지지만 않으면 됩니다.)

  폴더 안에 이런 파일들이 있습니다 ─

   [내가 직접 보는 파일]
     readme.txt .............. 지금 읽는 이 파일
     eval_section_sample.md .. 작성 예시 (직접 쓰실 분만 열어보면 됨)

   [LLM(ChatGPT·Claude)에게 '복사해서 줄' 파일 — 내가 읽을 필요 없음]
     LLM_프롬프트.md .......... 글 작성을 LLM에 맡길 때 주는 프롬프트
     ppt_guideline_grad.md ... PPT 변환 규칙 (최신 고밀도 디자인 지침)

   [완성 예시 / 도구 — 안 건드려도 됨]
     evaluation_plan_v8.pptx ......... 완성된 평가 영역 PPT 예시 (최신·메인)
     team_project_plan_sample_v3.pptx . 다른 유형의 계획서 예시 (참고용)
     _preview 폴더 ............ 예시 슬라이드 미리보기 이미지
     (.py 로 끝나는 파일) ...... 변환 자동화 도구 (고급, 안 써도 됨)


----------------------------------------------------------------
 [1단계] 내 영역 '내용' 작성  ─ 두 가지 방법 중 편한 것 택1
----------------------------------------------------------------

 ▶ 방법 A.  마크다운이 익숙한 분 (직접 작성)
   1) eval_section_sample.md 파일을 메모장이나 에디터로 엽니다.
   2) 안에 있는 슬라이드 예시( ---  <!-- slide:1 --> ... 블록 )를 보고,
      똑같은 형식으로 '내 영역 내용'으로 바꿔 씁니다.
   3) 다른 이름으로 저장합니다.  예) 기술_홍길동.md

 ▶ 방법 B.  마크다운이 낯선 분 (LLM에 맡기기 — 추천)
   1) LLM_프롬프트.md 파일을 열어 "전체 내용을 복사(Ctrl+A → Ctrl+C)" 합니다.
   2) ChatGPT 또는 Claude 채팅창에 그대로 "붙여넣고" 전송합니다.
   3) 이어서 내 영역 내용을 '편한 방식 아무거나'(말로 설명 / 메모 /
      워드·한글 내용 붙여넣기)로 주면, LLM이 발표용 마크다운을 만들어 줍니다.
   4) LLM이 준 결과(--- 로 시작하는 텍스트)를 복사해서 저장합니다.
      · 메모장 열기 → 붙여넣기 → "다른 이름으로 저장"
      · 저장할 때 파일 이름 끝을  .md  로 (예: 기술_홍길동.md)
      · '파일 형식'은 "모든 파일"로 두고 저장


----------------------------------------------------------------
 [2단계] 내 마크다운을 'PPT'로 변환해 보기  (샘플 체험)
----------------------------------------------------------------
  가장 쉬운 방법 — LLM(Claude 추천)에게 시키기:

   1) Claude 채팅창에 아래 두 파일을 첨부(또는 내용 복사)합니다.
        · 내가 만든 마크다운 파일 (예: 기술_홍길동.md)
        · ppt_guideline_grad.md  (PPT 디자인 규칙)
   2) 이렇게 요청합니다:
        "첨부한 ppt_guideline_grad.md 규칙에 맞춰,
         내 마크다운 내용을 PowerPoint(.pptx) 파일로 만들어줘."
   3) LLM이 .pptx 파일을 만들어 줍니다. 받아서 열어보면 됩니다.

  ※ 완성되면 evaluation_plan_v8.pptx 같은 느낌으로 나옵니다.
    (미리보기는 _preview 폴더의 이미지 참고)
  ※ 처음엔 디자인이 조금 어긋날 수 있어요. "글자가 넘쳐", "줄을 더 줄여줘"
    처럼 한 번 더 말해주면 LLM이 고쳐 줍니다.


----------------------------------------------------------------
 [3단계] 작업한 자료 공유하기
----------------------------------------------------------------
 ▶ 제일 쉬운 방법:  그냥 카카오톡
     내가 만든 .md (와 .pptx) 파일을 팀 카톡방에 올리면 끝입니다.

 ▶ 깃헙(GitHub)에 올리고 싶은 분:
     1) (팀 깃헙 주소)  ← 여기 접속 후 로그인
     2) 화면의  "Add file"  →  "Upload files"  클릭
     3) 내 파일을 마우스로 끌어다 놓기
     4) 아래로 내려  "Commit changes" (초록 버튼) 클릭  → 끝
     ※ 깃헙이 처음이라 헷갈리면 그냥 카톡으로 보내주세요. 합쳐서 올려드립니다.
