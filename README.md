> ★ **이 페이지(README) 만 읽으시면 됩니다.** 문서 변환 규칙은 LLM이 알아서 처리합니다.

각자 맡은 영역(평가 / 기술 / 데이터 등)의 발표 내용을 작성하면, 나중에 하나로 합쳐 **디자인이 통일된 PPT**로 만드는 팀 공용 키트입니다. **'평가 영역'** 을 샘플로 작성해 놓았으니 참조하시면 될 것 같습니다.(샘플 버전이라 내용 충실도는 아직 보지 말아주세요;)

> 💡 **마크다운/코딩 몰라도 됩니다.** 아래 [1단계]의 **방법 B**(LLM에 맡기기)를 쓰시면 됩니다.

## [1단계] 내 영역 '내용' 작성 — 둘 중 편한 것

### 방법 A. 마크다운이 익숙한 분 (직접 작성)
1. `eval_section_sample.md` 를 열어 슬라이드 예시 형식을 봅니다.
2. 같은 형식으로 **내 영역 내용**으로 바꿔 씁니다.
3. 다른 이름으로 저장 (예: `기술_홍길동.md`)

### 방법 B. 마크다운이 낯선 분 (추천)
1. `LLM_프롬프트.md` 전체를 복사 (Ctrl+A → Ctrl+C).
2. ChatGPT / Claude 채팅창에 **붙여넣고 전송**.
3. 이어서 내 영역 내용을 **편한 방식 아무거나**(말로 설명 · 메모 · 워드/한글 붙여넣기)로 주면, LLM이 발표용 마크다운을 만들어 줍니다.
4. 결과를 복사해 `기술_홍길동.md` 로 저장
   (메모장 → 붙여넣기 → '다른 이름으로 저장' → 파일 형식 **모든 파일**, 이름 끝 **`.md`**)

## [2단계] 마크다운 → PPT로 변환 (샘플 체험)

LLM(Claude 추천)에게 시키기 ─
1. 채팅창에 **① 내 마크다운 파일 ② `ppt_guideline_grad.md`** 를 첨부(또는 내용 복사).
2. 이렇게 요청: *"첨부한 ppt_guideline_grad.md 규칙에 맞춰, 내 마크다운 내용을 PowerPoint(.pptx) 파일로 만들어줘."*
3. LLM이 `.pptx` 를 만들어 줍니다. 받아서 열어보면 됩니다.

> 완성되면 `evaluation_plan_4slides_v4.pptx` 같은 느낌으로 나옵니다. 디자인이 조금 어긋나면 *"글자가 넘쳐"*, *"줄을 더 줄여줘"* 처럼 한 번 더 말하면 LLM이 고쳐 줍니다.
> (제출용 최종 PPT는 나중에 팀원들 마크다운을 하나로 모아 한 번에 변환할 예정입니다.)

## [3단계] 작업한 자료 공유

- **제일 쉬움**: 만든 `.md`((선택) `.pptx`)를 **팀 카톡방**에 올리면 끝.
- **깃헙에 올리기**: `Add file` → `Upload files` → 파일 끌어다 놓기 → 아래 `Commit changes`.
  - 깃헙이 처음이라 헷갈리면 그냥 **카톡으로**
