# 6개 조합 공통 채점 규칙

2026-11-11, 공통 채점 결과를 보기 전에 고정했습니다. 문서 20개로 채점기 동작만 확인했고, 그 값은 비교에 쓰지 않습니다.

## 대상

| 연구 | 조합 (Teacher → Student) |
|---|---|
| generic-kd-v1 | Qwen3.5 9B → 4B, Gemma 4 12B → E2B, LFM2.5 24B → 2.6B |
| small-model-v1 | Qwen3 8B → 1.7B, Gemma 3 12B → 1B, Kanana 1.5 8B → 2.1B |

조합마다 선택된 CE·KD Student를 seed 42·43·44로 3개씩, 모두 36개를 채점합니다. 학습 전 Student 6개는 참고용으로 함께 채점하고 판정에는 쓰지 않습니다. Teacher는 서비스 후보가 아니어서 제외합니다.

## 지표

- 데이터: 공통 cohort의 validation 851개 문서. test는 쓰지 않습니다.
- 범위: 문서마다 앞쪽 64바이트 이후 6개 토크나이저가 모두 토큰을 시작하는 첫 위치부터 문서 끝까지. 모든 모델이 똑같은 2,917,159바이트를 예측합니다(`results/small-model-v1/common/coverage-summary.json`).
- 값: bits-per-byte = 전체 bits 합 ÷ 전체 바이트. 최대 512토큰 문맥의 슬라이딩 윈도(stride 256), BOS 없음, FP32 log-softmax.
- 조합의 대표값: KD seed 3개의 bits-per-byte 평균. 서비스에 쓸 모델이 KD 버전이기 때문입니다. CE도 같은 방식으로 함께 보고합니다.

## 비교와 판정

- 조합 쌍마다 상대 차이 = (A − B) / B, KD 대표값 기준. 6개 조합이라 15쌍입니다.
- 불확실성: 문서 851개를 복원추출해 10,000번 다시 계산한 95% 구간(paired document bootstrap). 매번 각 모델의 bits 합 ÷ 바이트 합을 다시 계산합니다.
- **주 기준 마진 1%**, **보조 분석 마진 0.5%**. 결론은 주 기준으로 내고, 보조 분석은 판정이 마진에 얼마나 민감한지 보여 주기 위해 함께 보고합니다.

| 95% 구간 | 판정 |
|---|---|
| 전부 −마진 ~ +마진 안 | 동률 |
| 전부 마진 밖 | 우위 |
| 마진 경계에 걸침 | 판단 유보 |

## 해석의 한계

- validation은 체크포인트 선택에 쓰였으므로 모든 모델의 값이 조금씩 낙관적입니다. 36개 모두 같은 조건입니다.
- 학습 환경이 다릅니다(generic-kd-v1은 A100, small-model-v1은 3090). 채점은 모두 같은 3090 서버에서 합니다. 원우 체크포인트를 이 서버에서 복원했을 때 기록과의 CE 차이는 0.000034였습니다.
- Qwen3.5는 이 환경에 선형 어텐션 전용 커널이 없어 PyTorch 기본 구현으로 계산합니다.
- 15쌍 비교의 구간은 다중 비교 보정을 하지 않은 값입니다.
- seed 3개는 학습 반복의 흔들림만 보여 줍니다. 이 지표는 평문 예측 능력이며, QA, 안전, 기기 성능은 따로 평가해야 합니다.
