# 지식 증류 기반 경량 언어모델 연구 — 실버케어 온디바이스 AI를 적용 시나리오로

> 본 보고서는 **경량 언어모델 연구**를 메인 주제로 하며,
> 실버케어 온디바이스 AI는 연구 결과의 활용 가치를 설명하기 위한 **적용 시나리오**로 다룬다.

---

## 1. 프로젝트 개요
본 프로젝트의 핵심 목표는 대형 언어모델이 가진 성능을 작은 모델에서도 최대한 재현할 수 있도록 하는 **경량화 방법을 연구**하는 것이다.

이를 위해 **지식 증류(Knowledge Distillation)를 중심**으로 Teacher Model의 지식과 응답 특성을 Student Model에 전달하는 방식을 실험한다. 필요에 따라 프루닝, 양자화 등 추가적인 모델 압축 기법도 함께 고려할 수 있다.

본 연구는 단순히 모델 경량화 성능을 비교하는 데 그치지 않고, 경량화 모델이 실제로 필요한 활용 분야를 함께 검토한다. 그중 **하나의 적용 시나리오로 실버케어 온디바이스 AI를 선정**하였다.

실버케어 환경은 고성능 서버나 대형 모델을 직접 사용하기 어렵고, 네트워크 연결성·개인정보 보호·디바이스 성능 제약이 존재할 수 있기 때문에 경량화 모델의 필요성과 당위성을 설명하기에 적합하다.

> 즉, **연구의 본체는 경량 언어모델 연구**이며, 실버케어는 그 결과의 가치를 검증하기 위한 적용 분야이다.

---

## 2. 연구 필요성 및 적용 분야 선정 배경

### 2.1 경량 언어모델 연구의 필요성
대형 언어모델은 높은 성능을 보이지만, 실제 서비스 환경에서는 다음과 같은 한계가 있다.

- 모델 크기가 커서 일반 디바이스에 탑재하기 어려움
- 추론 비용과 연산 자원이 많이 필요함
- 네트워크 연결이 필요한 경우가 많음
- 실시간 응답이 필요한 환경에서는 지연 시간이 문제가 될 수 있음
- 민감한 데이터를 서버로 전송해야 하는 경우 개인정보 이슈가 발생할 수 있음

따라서 대형 모델의 성능을 최대한 유지하면서도 작은 모델로 동작할 수 있는 **경량화 연구가 필요**하다.

### 2.2 적용 시나리오로 실버케어를 선택한 이유
경량화 모델 연구를 기반으로, 실제 적용 가능성이 높은 분야를 찾는 과정에서 실버케어를 **활용 시나리오로 선정**하였다.

실버케어 환경에서는 다음과 같은 요구가 존재할 수 있다.

- 독거노인의 말동무 및 정서적 지원
- 건강 상태 관련 대화 지원
- 네트워크가 불안정하거나 연결이 어려운 환경
- 개인정보가 포함된 생활·건강 데이터 보호 필요
- 고성능 디바이스 사용이 어려운 환경

이러한 조건은 **경량 언어모델이 필요한 이유를 설명하기에 적합**하며, 온디바이스 AI 적용 가능성을 검토하기 좋은 사례가 된다.

## 3. 이론적 배경
본 프로젝트에서는 모델 경량화를 위한 대표적인 방법들을 검토한다.

### 3.1 지식 증류
지식 증류는 성능이 높은 Teacher Model의 출력, 응답 패턴, 추론 능력을 더 작은 Student Model이 학습하도록 하는 방법이다.

이를 통해 작은 모델이 대형 모델과 유사한 응답 품질을 내도록 하는 것이 목표다.

### 3.2 추가 경량화 기법
지식 증류 외에도 다음과 같은 기법을 함께 고려할 수 있다.

- **프루닝**: 모델 내 중요도가 낮은 파라미터나 구조를 제거
- **양자화**: 모델 가중치의 정밀도를 낮춰 메모리 사용량과 연산량 감소
- **모델 압축**: 경량 모델 구조를 활용하여 추론 효율 개선

본 프로젝트에서는 **지식 증류를 중심**으로 하되, 필요에 따라 다른 경량화 기법과의 결합 가능성도 검토한다.

## 4. 데이터 구성
본 프로젝트의 데이터는 두 가지 관점에서 검토한다.

### 4.1 경량화 학습을 위한 데이터 *(연구 본체)*
Teacher Model의 응답을 Student Model이 학습하기 위한 질의응답 데이터가 필요하다.

- 일반 질의응답 데이터
- 도메인 특화 질의응답 데이터
- Teacher Model이 생성한 응답 데이터
- 평가용 벤치마크 데이터

### 4.2 실버케어 적용 시나리오를 위한 데이터 *(적용 검증용)*
실버케어 활용 가능성을 검토하기 위해 다음과 같은 데이터를 후보로 고려한다.

- AI Hub 데이터
- 의료 관련 데이터
- 실버케어 관련 대화 데이터
- 생활 패턴 및 라이프로그 기반 질의응답 데이터

### 4.3 데이터 선정 기준
- 경량화 학습에 활용 가능한 구조인지
- 질의응답 형태로 변환 가능한지
- 실버케어 시나리오와 연관성이 있는지
- 개인정보 및 민감정보 이슈를 통제할 수 있는지
- 평가 데이터로 활용 가능한지

## 5. 구현 현황
현재 구현 단계는 실버케어 서비스를 완성하는 단계가 아니라,
**지식 증류 기반 경량 언어모델 실험 환경을 구축하고 1차 실험을 수행한 단계**이다.
이번 실험에서는 Teacher Model로 GPT-2, Student Model로 DistilGPT-2를 사용하였다.

### 5.1 실험 조건

| 항목 | 값 |
|---|---:|
| Teacher | GPT-2, 124M, 497.8MB |
| Student | DistilGPT-2, 82M, 327.7MB |
| 압축률 | 파라미터 약 34% 감소, 용량 약 34% 감소 |
| Temperature | 4.0 |
| Alpha | 0.3 |
| KD Loss | 0.3·CE + 0.7·T²·KL |
| Epochs | 3 |
| Batch Size | 4 |
| max_seq_length | 256 |
| Device | Apple MPS, MacBook |

### 5.2 구현 내용
- GitHub 저장소 생성
- 브랜치 기반 협업 구조 구성
- Teacher / Student 모델 구조 구성
- GPT-2와 DistilGPT-2 기반 지식 증류 실험
- KD Loss 계산 구조 구현
- 학습 로그 및 결과 저장 구조 구성
- PPL, loss, 추론 속도 등 평가 지표 확인

### 5.3 현재 구현의 의미
현재 구현은 최종 성능 검증 단계가 아니라,
지식 증류 실험이 가능한 **기본 파이프라인을 구축한 단계**이다.

이번 실험을 통해 Teacher Model과 Student Model을 설정하고,
Student Model이 Teacher Model의 출력 분포를 학습하는 구조를 확인하였다.

또한 모델 크기 감소와 추론 속도 개선 가능성을 확인하였으며,
향후 더 정교한 평가를 위해 PPL 계산 방식과 데이터 처리 방식을 개선할 필요가 있다.

### 5.4 현재 확인된 이슈
- PPL 수치가 비정상적으로 나타날 가능성이 있음
- padding token 처리에 따라 loss가 왜곡될 수 있음
- causal language model 특성상 label shift 처리가 중요함
- 현재 실험은 MacBook MPS 환경에서 수행되어 대규모 실험에는 한계가 있음
- 향후 GPU 서버 환경에서 더 큰 모델과 데이터셋을 활용한 실험이 필요함

## 8. 최종 목표 및 향후 계획
본 프로젝트의 최종 목표는 **지식 증류를 중심으로 한 경량 언어모델 연구를 수행**하고, 해당 모델이 실제 서비스 환경에서 활용될 수 있는 가능성을 검토하는 것이다.

실버케어는 그 **적용 가능성을 설명하기 위한 대표 시나리오**로 활용한다.
향후에는 데이터 선정, 학습, 평가를 통해 경량화 모델의 성능과 실효성을 함께 검증할 계획이다.

### 8.1 실험 환경에 대한 보충
현재까지 진행된 1차 실험(5장)은 **로컬 리소스 제약**으로 인해
모델 규모·데이터 크기·학습 시간이 모두 제한된 시나리오 기반으로 수행되었다.
따라서 현재 결과만으로 지식 증류의 효과를 단정짓기는 어렵다.

이를 보완하기 위해 후속 실험은 **학교에서 제공하는 GPU 센터 환경**을 활용하여
보다 충분한 자원 위에서 검증을 진행한다.

### 8.2 향후 진행 단계
향후 계획은 다음과 같이 **2단계**로 구분하여 진행한다.

#### Phase 1. GPU 센터 기반 지식 증류 추가 검증 *(연구 본체 보강)*
> 로컬 환경 제약으로 검증이 부족했던 부분을 GPU 센터에서 재실험하여,
> 지식 증류 자체의 효과와 신뢰할 수 있는 평가 지표를 먼저 확보한다.

- 학교 GPU 센터 환경 설정 및 코드 이식
- 동일 조건에서의 재현 실험 (PPL, loss, 추론 속도 재측정)
- 5.4의 이슈 해소 (label shift, padding masking, PPL 계산 정합성)
- 더 큰 모델·데이터·epoch 조건으로 확장 실험
- Temperature, Alpha 등 하이퍼파라미터 민감도 분석
- 프루닝·양자화 등 추가 경량화 기법과의 결합 검토

#### Phase 2. 실버케어 적용 시나리오 기반 후속 실험 *(적용 검증)*
> Phase 1에서 검증된 지식 증류 설정을 바탕으로,
> 실버케어 적용을 전제로 한 실제 서비스용 모델·데이터로 재선정하여 후속 실험을 진행한다.

- 실버케어 적용을 위한 Teacher / Student 모델 재선정 (한국어 지원, 온디바이스 가능 규모)
- 실버케어 시나리오에 맞는 학습 데이터 선정 및 정제
- Teacher Model 기반 응답 데이터 생성
- Student Model 학습
- 온디바이스 배포를 위한 프루닝·양자화 적용 및 튜닝
- 모델 성능 평가
- 실버케어 시나리오 기반 응답 평가
- 스탠드얼론 또는 온디바이스 환경에서의 구동 가능성 검토
