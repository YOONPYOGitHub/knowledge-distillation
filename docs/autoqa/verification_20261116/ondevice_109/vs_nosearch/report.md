## 한눈에

- 미리 정한 규칙: 아래 셋을 모두 지키면 "ondam_local_rag 가 ondam_local_only 에 밀리지 않는다"로 쓴다.

- ❌ 직접 비교 선호율 95% 구간 하한이 40% 이상 (지금 45.5%, 구간 36~55%)

선호율 = (이긴 문항 + 비긴 문항의 절반) ÷ 문항 수. 50% 면 대등하다.
- ⚠ 골든셋 109문항 중 100문항만 짝이 됐다 (한쪽 답이 없는 문항 9개). 아래 수치는 짝이 된 문항만의 값이고, 비열등 판정은 전체 문항이 모인 뒤에 낸다.

## 이 비교로 말할 수 없는 것

- 이 문항 수로는 Pass 비율 차이가 ±12%p 안이면 가려내지 못한다. 여유폭(10%p)보다 넓어, 두 시스템이 같아도 Pass 조건을 못 넘을 수 있다.
- 구간은 이 질문 묶음 안에서 잰 값이다. 골라 만든 문항이라 실제 어르신 질문 전체를 대표하지 않는다.
- 골든셋 `v0.4-draft-20261114` · draft (전문가 검수 전). 기준이 틀렸으면 판정도 틀린다.
- 비교 상대 `ondam_local_only` 의 기록: prompt_format=ondam-api · source=ondam-api. 이 기록에 없는 모델 이름으로 부르지 않는다.
- 한 번 묻고 답하기만 봤다. 이어지는 대화와 음성은 보지 않았다.
- 채점 모델은 claude-opus-5-5 하나다. 사람(약사·간호사)과의 일치도는 따로 잰다.
- 두 시스템 모두 통과하지 못한 문항이 54개다. 나란히 고른 결과만 보면 이것이 가려진다.
- 각자 판정은 같은 답을 두 번 채점해 나쁜 쪽을 쓴 값이다. 한 번 채점한 회차와 견주지 않는다.
