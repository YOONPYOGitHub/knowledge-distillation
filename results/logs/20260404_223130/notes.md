### 6. 원인 분석 — 왜 T/α가 효과 없는가

**Teacher의 지식 한계가 병목.**

```
Student (FT)  PPL = 32.7   ← Teacher(43.6)보다 이미 좋음
Teacher       PPL = 43.6
Student (KD)  PPL = 48.7   ← Teacher보다 나쁨
Student Base  PPL = 65.3
```

- FT가 Teacher보다 PPL이 낮다 = Student가 이 데이터에서 Teacher보다 잘 학습함
- KD는 "Teacher 분포를 모방"하는 것이므로, Teacher가 FT보다 못하면 KD가 FT를 이길 수 없음
- T/α를 아무리 조정해도 **Teacher 자체의 정보량**은 변하지 않음

### 7. 다음 실험 방향

T/α 튜닝이 효과 없으므로 **변수를 바꿔야 함.** 두 가지 방향이 있고, 각각 다른 가설을 검증한다.

#### 방향 A: gpt2-medium Teacher (355M) — "더 좋은 선생" 가설

현재 Teacher(gpt2, PPL=43.6)가 FT(PPL=32.7)보다 나쁘기 때문에, KD는 "못하는 선생에게 배우는 것"이 되어버림. gpt2-medium(PPL ~26)을 쓰면 Teacher가 FT보다 확실히 나아지므로, soft label에 담긴 지식이 실질적인 가치를 가짐.

- 기대: Teacher PPL ~26 < FT PPL ~32.7 → KD가 FT를 이길 조건 성립

#### 방향 B: WikiText-103 (103M 토큰) — "일반화 능력" 가설

현재 WikiText-2(2M 토큰)에서는 FT가 데이터를 거의 외울 수 있어서, 테스트에서도 좋은 성적을 냄. 데이터가 50배 커지면 외우기 전략이 통하지 않고, KD의 일반화 효과가 드러남.

WikiText-2(AS-IS):
- FT: 데이터가 작아 거의 암기 가능 → 테스트에서도 OK → PPL=32.7
- KD: Teacher 모방 + 정답 학습 동시진행 → 수렴 느림 → PPL=48.7 (FT에게 짐)

WikiText-103(TO-BE):
- FT: 데이터 50배 → 암기 불가 → 처음 보는 패턴에서 약점 노출 → PPL 상승 예상
- KD: Teacher soft label이 "정답은 A지만 B, C도 가능"이라는 분포 정보를 줌 → 단순 암기가 아닌 일반적 언어 패턴을 학습 → 새로운 문맥에서도 합리적 예측 → PPL이 FT보다 낮아질 가능성

- 기대: FT의 외우기 전략이 안 통하는 환경에서 KD의 정규화 효과 확인

**→ PC에서 가능한 방향 A(gpt2-medium Teacher)를 먼저 실험: exp04 진행**
